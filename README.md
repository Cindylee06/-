# -
本项目依托高云SipeedTang系列开发板TangNano20K，搭建了一套全硬件并行波形合成电子乐器系统，全部音频算法采用VerilogHDL硬件描述语言开发，无软核处理器参与运算。系统内置多类型波形振荡器、ADSR包络发生器、FIR/IIR数字滤波器、FM调制模块，实现了波形采样、加法合成、物理建模等多种音色生成算法；支持≥4复音并发输出，通过12S总线输出至DAC，演奏总延迟控制在10ms以内，满足赛题基础指标。系统采用电容触摸、光电手势实现多维演奏交互；拓展功能完成8复音并行合成、混响合唱音效处理，搭配LED状态指示与蓝牙APP联动调参。项目充分利用FPGA天然并行流水线特性，做到音频信号硬件实时计算，资源可配置、时延极低，可作为可编程实时数字音频平台，用于交互式电子乐器开发。
